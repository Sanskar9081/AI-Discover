AI Discover 🚀

AI Discover is a modern AI tool discovery and comparison platform that helps users explore, search, compare, and save AI tools efficiently in one place.

✨ Features
🔍 Advanced AI tool search and filtering
⚖️ Tool comparison dashboard
🤖 AI Assistant integration
❤️ Save & recently viewed tools
🌙 Dark mode support
👤 User authentication system
📱 Fully responsive UI
⚡ Fast and optimized performance
🛠️ Tech Stack
React.js
TypeScript
Tailwind CSS
Supabase
PostgreSQL
Vite
📌 Modules
Homepage
Tools Page
Tool Detail Page
Comparison Dashboard
AI Assistant
Saved Tools
User Authentication
Admin Management
🎯 Objective

The main objective of AI Discover is to provide a centralized platform where users can discover, compare, and analyze AI tools easily without searching across multiple websites.
